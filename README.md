# 🌍 GeoSpatial Analysis with Python

A collection of geospatial data analysis and visualization projects using Python. This repository demonstrates how to work with vector and raster datasets, perform spatial analysis, and create insightful visualizations.

## 🚀 Technologies Used

| Library | Purpose |
|----------|----------|
| NumPy | Numerical computations and array operations |
| Pandas | Data cleaning and tabular data analysis |
| GeoPandas | Working with shapefiles and spatial vector data |
| Matplotlib | Data visualization and mapping |
| Rasterio | Reading and processing raster datasets (NDVI, satellite imagery, DEM, etc.) |

---

## 📊 Features

### Vector Data Analysis
- Read and visualize shapefiles
- Explore district and state boundaries
- Spatial joins
- Attribute analysis

### Raster Data Analysis
- Read GeoTIFF files
- Extract raster values
- NDVI analysis
- Raster statistics

### Data Analysis
- Rainfall analysis
- District-wise comparisons
- Statistical summaries
- Data preprocessing

### Visualization
- Choropleth maps
- Bar charts
- Histograms
- Thematic maps

## 📈 Sample Applications

- Rainfall distribution analysis

- District-level geospatial visualization
- Agricultural monitoring
- Environmental studies
- Remote sensing projects

This repository serves as a foundation for future geospatial and Earth observation projects involving satellite imagery, environmental monitoring, and spatial intelligence.
